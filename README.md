# AI Blueprint Generator

При написании плагина были использованы нейросети.
Плагин для **Unreal Engine 5.8** (редакторный), который строит и правит ноды Blueprint и материалов с помощью **любой внешней нейросети** — вручную, через копирование.
Никаких API-ключей, провайдеров и HTTP-запросов внутри плагина нет: вы копируете готовый промпт, вставляете его в чат с ИИ (ChatGPT, Claude, Gemini, локальная модель — что угодно), а ответ целиком вставляете обратно. Плагин сам находит в ответе JSON и собирает ноды.

> English: a copy-paste Unreal Engine 5.8 editor plugin. It copies a ready prompt (with the context of your Blueprint / material / project), you paste it into any AI chat, paste the whole reply back, and the plugin extracts the JSON and builds the nodes. No API keys, no network code. Not commercial-use friendly: see [License](#лицензия).

Статус: ранняя версия `0.1.0` (beta), проверялась на UE 5.8.4 / Windows.

## Что умеет

- **Blueprint**: промпт с описанием открытого Blueprint (переменные, компоненты, функции, существующие ноды), вставка ответа создаёт ноды и связи. Профили под тип Blueprint (Actor, Component, Widget, Level, Function/Macro Library, Interface и др.).
- **Материалы и Material Function**: JSON с `settings / nodes / connections / disconnect / remove`, текущие ноды материала передаются ИИ с id (`e_Multiply_0`), чтобы можно было менять существующее. Новые ноды раскладываются по колонкам вдоль проводов.
- **Создание новых ассетов** (меню **AI Generator** в строке меню редактора, перед Help): Blueprint (Actor, Component, Pawn и т.д.), Widget Blueprint, Material, Material Function. Если нужны текстуры, ИИ может сослаться на существующие ассеты или на файлы на диске — плагин их импортирует.
- **Структура проекта в промпте** (необязательно): весь проект, одна папка, фильтры по типам (текстуры, материалы, Blueprint, меши, анимации, звуки, виджеты), C++ классы проекта — чтобы ИИ видел реальные пути и не выдумывал ассеты.
- **Ошибки → готовый промпт для исправления**: если ответ не применился, показываются причины и копируется промпт с ошибками для следующей итерации. Применение «всё или ничего»: сначала проверка, потом изменения.
- **Кнопка «Разложить ноды»** в окне материала: раскладывает все ноды по колонкам (полезно, если ноды слиплись).
- **История**: каждый скопированный промпт, fix-промпт и применённый ответ сохраняются в `<Проект>/Saved/AIBlueprintGen/History/` (последние 100, число меняется в настройках).

## Установка

Нужны: **Windows**, установленный **Unreal Engine 5.8** (Epic Games Launcher) и **Visual Studio** с рабочей нагрузкой «Game development with C++» (тот же набор, что нужен самому Unreal). Плагин собирается один раз штатным `RunUAT BuildPlugin`.

### Установщик (рекомендуется)

1. Либо скачайте готовый **`AIBlueprintGen-Setup.exe`** (раздел Releases; один файл, всё нужное внутри), либо скачайте репозиторий (**Code → Download ZIP**), распакуйте и запустите `Installer\Install.bat`.
   Exe не подписан, поэтому Windows SmartScreen может предупредить («Подробнее → Выполнить в любом случае»).
2. Откроется окно установщика.
3. Выберите, куда ставить:
   - **В проект** — укажите `.uproject`; движок определяется автоматически по проекту (его можно сменить в списке). Плагин собирается и копируется в `<Проект>\Plugins\AIBlueprintGen`, в `.uproject` добавляется запись о включении (резервная копия `.uproject.bak`). Права администратора не нужны.
   - **В движок** — выберите найденный движок (список строится сам, новейший первым). Плагин собирается и копируется в `<Движок>\Engine\Plugins\Marketplace\AIBlueprintGen`, потребуется подтверждение UAC. После этого в каждом проекте включите плагин: **Edit → Plugins → AI Blueprint Generator**.
4. Кнопка **«Удалить»** убирает плагин из выбранного проекта / движка.

Установщик можно запускать без окна:

```bat
Installer\Install.bat -Mode Project -Project "D:\Games\My\My.uproject"
Installer\Install.bat -Mode Engine  -Engine  "C:\Program Files\Epic Games\UE_5.8"
Installer\Install.bat -Mode Project -Project "D:\Games\My\My.uproject" -NoBuild      :: только исходники
Installer\Install.bat -Mode Project -Project "D:\Games\My\My.uproject" -Uninstall
```

Самораспаковывающийся `.exe` собирается так (нужен Python):

```bat
pip install ziglang
python Installer\build_exe.py
```

Результат: `dist\AIBlueprintGen-Setup.exe` (внутри — репозиторий в zip; при запуске распаковывается во временную папку и открывает то же окно установщика).

### Вручную

Скопируйте папку `AIBlueprintGen` (та, где лежит `AIBlueprintGen.uplugin`) в `<Проект>\Plugins\`, перегенерируйте проект и откройте его; на запрос о пересборке модулей ответьте «Yes». Для проекта без C++ собранные бинарники даёт установщик.

Плагин привязан к версии движка: для другой версии нужна пересборка (установщик делает это сам).

## Как пользоваться

1. Откройте Blueprint или материал. Окно плагина — **Window → AI Blueprint Generator** внутри самого редактора (у каждого редактора своя привязанная вкладка) или общее окно из меню **AI Generator** в строке меню уровня.
2. В поле **«1. Запрос»** опишите, что нужно, нажмите **«Скопировать промпт для нейронки»** и вставьте в чат с ИИ.
3. Ответ ИИ целиком (с пояснениями) вставьте в **«2. Ответ нейронки»** и нажмите **«Вставить в Blueprint»** (для нового ассета — **«Создать ассет»**).
4. Если не получилось, в **«3. Ошибки»** будут причины и кнопка **«Скопировать промпт с ошибками»** — отправьте его ИИ и вставьте исправленный ответ.

Изменения не сохраняются автоматически: сохраните ассет (Ctrl+S) сами. Отмена — Ctrl+Z.

## Настройки

**Editor Preferences → Plugins → AI Blueprint Generator**: инструкции для каждого типа ассета, папка для новых ассетов по умолчанию, ограничения промпта, число записей истории.

## Известные ограничения

- Ранняя версия: возможны ошибки. Результат работы ИИ всегда нужно проверять глазами.
- ИИ может ответить «это невозможно» (`unsupported`) или выдумать несуществующие ноды/пины; в этом случае ничего не меняется, а причина попадает в fix-промпт.
- Плагин не знает, что вы видите на экране: проблемы вида «материал чёрный» вызваны не только графом (UV, освещение, настройки текстур) — их ИИ по JSON не увидит.
- Только Windows (установщик) и только UE 5.8.
